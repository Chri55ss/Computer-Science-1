# DogShelterV0.1

Run the improved game from this folder:

```powershell
python dog_shelter_game_better.py
```

Accept a dog during intake before looking it up. Choose **View Dog Database**,
type the dog's name (capitalization does not matter), and the game will show
the dog's record. You can choose to provide care from that prompt. **Check
Dogs** in the main menu also lets you find a dog by name and provide care.
